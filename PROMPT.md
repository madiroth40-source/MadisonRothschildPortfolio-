# Claude Code Prompt — Madison Rothschild Marketing Portfolio

Copy/paste the prompt below into Claude Code to (re)generate or iterate on the portfolio.

## The Prompt

You are building a personal marketing portfolio website for **Madison Rothschild**,
a marketer specializing in organic content, UGC, creative marketing, and brand
strategy. The site must feel **sleek, trendy, and modern** — editorial and
high-end, like a fashion magazine crossed with a premium agency site.
Think: oversized serif typography, generous whitespace, warm neutral palettes
(cream, taupe, charcoal, blush), subtle script accents, large numeral statistics,
and image-forward layouts.

### Required sections (in order on the home page)

1. **Hero** — Madison's name large and editorial, a one-line positioning
   statement ("Marketing portfolio — content, creative & brand strategy"),
   and a call-to-action button ("Work with me" / "View work").
2. **Four pillars** — a featured grid showcasing her four marketing strengths:
   - **Creative** — concepting, art direction, campaign ideas with creative drive
   - **Strategy** — go-to-market strategy, brand positioning, channel planning
   - **Analytics** — ROI measurement, pipeline optimization, performance reporting
   - **Content Writing** — brand voice, copywriting, storytelling across channels
3. **About Me** — warm, confident bio with a photo placeholder. Emphasize her
   passion for go-to-market strategy and creative drive.
4. **Content** — deep-dive section covering: organic content, UGC,
   and creative marketing, framed by her GTM-strategy passion.
5. **Brand Strategy** — deep-dive section covering: positioning, brand voice,
   campaign development, pipeline driving, and analytics for ROI and
   pipeline optimization.
6. **Stats / proof bar** — large editorial numerals (e.g., campaigns shipped,
   pipeline influenced, content pieces produced) as placeholders to edit later.
7. **Contact / footer** — email CTA, social links, clean footer.

### Design requirements

- Fully responsive, mobile-first.
- Self-contained HTML + CSS (Google Fonts allowed, no build tooling) so it can
  be hosted on GitHub Pages instantly.
- Smooth scroll, subtle hover states and reveal animations — tasteful, not flashy.
- Use placeholder blocks for photography (warm gradients) that are easy to
  swap with real images.
- Accessible: semantic HTML, sufficient contrast, alt text on images.

### Deliverables

Produce **three distinct visual directions** so the strongest can be chosen:

1. **Editorial** — light warm-gray/taupe palette, oversized condensed display
   type, magazine-style grid, script accents (inspired by UGC-creator
   portfolio decks).
2. **Noir** — near-black hero, cream serif typography, luxury coach-site
   energy, big numeral statistics, press-bar styling.
3. **Soft Studio** — cream/blush/tan palette, rounded cards, friendly warmth,
   stat callouts (inspired by soft UGC portfolio sites).

Each variant lives in its own HTML file, with an `index.html` that links to
all three for side-by-side comparison.
